Project leadMicrolearning29 languages

A1 module reshuffle: from 1-hour SCORM to microlearning

Project I led to split the most-used A1 modules into four 15-minute parts, with a new look and feel, keyboard accessibility, and an onboarding tutorial.

Tools: Articulate Storyline, SCORM delivery on EU Academy.

Scope: A1 modules 1–3, each split from one 1-hour SCORM into four 15-minute parts; 29 languages.

Usability tests and learner data showed that the first A1 modules, the most used in the catalogue, would work better as shorter units. I led the redesign: analysed the existing content in 29 languages to find what could fit a single Storyline template and to map language-specific exercises; defined how each activity would be migrated technically from the old template to the new one; built the English version of each part to prove the process; and wrote illustrated, step-by-step adaptation guidelines for the external instructional designers producing the other languages.

The new parts bring an updated look and feel, revised navigation, improved keyboard-only accessibility, and a short tutorial on navigation and accessibility features. On this voluntary, self-paced course, the programme’s final report found that splitting the modules measurably improved the learner experience and completion rates.
